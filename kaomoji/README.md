# 颜文字小铺

863 个可爱颜文字和符号零件，分 32 类，点一下就复制。线上地址：<https://peipei707.github.io/kaomoji/>

`index.html` 是生成出来的，不要直接手改。改内容请动 `data.txt` 或 `template.html`，然后：

```sh
node build.js      # 读 data.txt + template.html，重新生成 index.html
```

没有依赖，Node 18 以上即可。推到 `main` 之后页面自动更新。

`data.txt` 是纯文本，一行一个，格式是 `颜文字~~~搜索关键词`，`##` 开头的行是分类名：

```
## 开心
(*^▽^*)~~~开心 笑 happy
```

同一个颜文字重复出现时，构建脚本会把关键词并到一起，不会生成重复的格子。
「脸的零件」「装饰符号」「边框分隔」这三类会自动排到最后，表情先看。

页面本身的两个硬要求，改的时候别破坏：**单个 HTML 文件、没有任何外部依赖**（离线可用），
以及**每个格子都是静态 HTML**，没有 JavaScript 时也能看全内容、长按复制。
