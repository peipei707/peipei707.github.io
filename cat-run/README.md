# 五喵跑酷

像素风横版跑酷小游戏，家里五只猫任选：米粥、躲躲、黑虎、叨叨、汤圆。线上地址：<https://peipei707.github.io/cat-run/>

`index.html` 是手写的单个文件，没有构建步骤；推到 `main` 之后页面自动更新。字体从 Google Fonts
加载（站酷快乐体、Silkscreen），断网时退回系统字体，游戏照常能玩。

## 页面里有什么

| 猫 | 品种 | 技能 |
| --- | --- | --- |
| 米粥 | 狸花猫 | 二段跳 |
| 躲躲 | 玳瑁猫 | 被撞到时 1/3 机会躲开 |
| 黑虎 | 黑猫 | 从上面踩到任何障碍都不疼，还能弹起来 |
| 叨叨 | 白猫 | 下落时按住跳，慢慢飘 |
| 汤圆 | 英短蓝猫 | 多一条命、跳得低；空中按 ↓ 屁股墩，震飞旁边的东西 |

- **要躲开**：黄瓜、吸尘器、洗澡盆、蜜蜂、刚拖过的湿地板。**可以踩**：扫地机器人；剑麻猫窝是弹床。
- **零食箱**跳起来用头顶，掉小鱼干或道具：猫薄荷棒棒糖（无敌冲刺）、纸王冠（挡一次）、罐头（+1 命）。
  小鱼干攒 50 条也加一条命，最多九条命。
- 速度随时间变快，14 / 40 / 80 秒各解锁一档更难的障碍组合。跑到 1200 分左右天黑，2400 分左右天亮，
  之后一直循环（按跑过的距离算，不算奖励分）。
- 每只猫的最高分分别存在浏览器的 localStorage（`wumiao.best.<猫的 id>`）。

## 改的时候别破坏的几件事

**猫是拼出来的。** `HEAD_N` / `HEAD_R`（头）和 `BODY_N` / `BODY_C`（身体）是字符网格，腿和尾巴按
`POSES` 里的参数现画，最后自动描一圈边。网格里每个字母是一个「部位」，五只猫各自在 `pal` 里把部位
映射成颜色，比如额头那一道 `f`：米粥是白的，躲躲是橘的，其他猫跟毛色一样。改花色只动 `pal`，
改造型才动网格。

**画面是 320×180 的逻辑像素**，按整数倍放大（高密度手机屏上允许非整数铺满宽度）。所有坐标都按
逻辑像素算，`GY = 150` 是地板的上沿。

**物理是固定步长**（1/120 秒）。跳跃手感的几个数在文件最上面：`GRAV`、`JUMP`、`JCUT`（松手时截断
上升速度）。关卡模板 `PATS` 里的鱼干弧线和平台高度都是按这套数摆的，改了要一起看。

**模板之间的间距按当前速度算**（`spawnNext`）。会动的东西（扫地机器人、蜜蜂）用 `pre` 多留一段，
而且只在快进屏幕时才开始走；新加会动的模板记得给 `pre`。

**菜单、暂停、结算靠 `hidden` 属性切换**，CSS 里 `[hidden]{display:none!important}` 那一行不能删，
否则几个界面会叠在一起。

## 自测

`window.__wumiao` 是留给自动测试的入口：在无头浏览器里调 `__wumiao.startRun()`，再循环调
`__wumiao.update(1 / 120)` 就能快进。上线前用一个简单的自动躲障碍脚本让五只猫各跑了 150 秒，
没有报错。
