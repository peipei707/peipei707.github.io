# 波粒二象性 · 双缝实验台

可交互的双缝实验台加一篇长文。线上地址：<https://peipei707.github.io/double-slit/>

`index.html` 是手写的，没有构建步骤。单个 HTML 文件、没有任何外部依赖，离线打开也能跑；
推到 `main` 之后页面自动更新。

## 页面里有什么

- **三种波场渲染**：振幅实部 Re ψ、强度 |ψ|²、相位 arg ψ。
- **单粒子模式**：逐个发射、逐个记录，累积出条纹。
- **路径可辨识度 D 是连续滑块**：落点按 V = √(1 − D²) 采样，读数条里的「V 实测」是从真实
  直方图锁相提取的，可以自己核对 V² + D² ≤ 1；旁边配一张实时的 V–D 取舍关系图。
- **光标放到缝后任意一点**：画出到两条缝的两条路径，报出 Δr 等于多少个波长、亮纹还是暗纹。
- 缝口可以直接拖；λ、缝宽 a、发射率、时间流速都可调；延迟选择演示；德布罗意波长计算器。

## 改的时候别破坏的几件事

**单个 HTML 文件、零外部依赖。** 页面要能离线打开，也不依赖任何 CDN。

**复振幅场缓存。** `buildField()` 把每个像素的 `ψ₁`、`ψ₂` 拆成实部/虚部/模/相位存下来，
因为时间依赖只是一个整体相因子 `e^{-iωt}`；每帧只做一次混合。改渲染逻辑时别退回成
"每帧重算整场"，那会掉到 20 fps 以下。几何或 λ 变了要把 `fieldDirty` 置 `true`。

**强度视图必须是静止的。** 这不是 bug，是页面要讲的一个点（概率密度不含时间）。

**落点分布与理论曲线共用一个 `intensity(y)`。** 直方图、理论曲线、屏上条纹、概率云底衬
全都从它来，所以改公式时四处会同时变，不会互相打架。改完之后拿 D = 0 / 0.7 / 1 三档跑
两万次，核对读数条里的「V 实测」是否贴近 √(1 − D²)——这是最有效的一个自检。

**方向键和空格只在画面被点选之后才接管**（`document.activeElement === cvs`），
否则会抢掉正常翻页。

**物理上的诚实。** D = 1 时给的是宽阔的单缝包络，不是教科书插图上那两条细亮带；
「模型说明」那一节列了所有已知的简化，改动模型时记得同步更新它。
