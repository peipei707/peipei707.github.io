画面上有什么

左边是光源，中间竖着的是开了两条缝的挡板，右边那条竖线是底片，最右边的横条是落点计数直方图（青色实线是理论曲线，紫色虚线是关掉相干性后剩下的单缝包络）。

  • 波场模式渲染整个空间的波场。默认画的是振幅实部——青色为正、紫色为负，波纹会向外跑。切到强度就会看到它其实是静止的驻纹：这正是条纹能稳定停在底片上的原因。切到相位则用色环显示 arg ψ，缝后那些从中心辐射出去的"叉花"就是相位奇点所在的暗纹。
  • 单粒子模式一次只放一个粒子。飞过挡板之后，如果没有路径信息，它被画成横跨两条缝、逐渐收窄的一片亮雾；如果探测器读到了路径，它就变成一条从某条缝出发的确定轨迹。落点是一个个孤立的橙点，慢慢堆成条纹。
  • 把光标移到缝后的任何一点，画面会画出从两条缝到该点的两条路径，并直接报出路程差 Δr 等于多少个波长、该点属于亮纹还是暗纹。这是整个实验最核心的一行数。
  • 直接拖动缝口可以连续改变缝间距，条纹密度会跟着实时变化。
先试这个 按 2 切到单粒子模式，点「累积 1 000」，再点一次「累积 20 000」。看着毫无规律的随机点如何在统计上长出条纹，然后把「路径可辨识度」从 0 慢慢拧到 1。
一

条纹从哪来

波到达双缝后，每条缝都成为一个新的次级波源（惠更斯）。两列波在底片上相遇，走过的路程一般不等：路程差是波长整数倍的地方，波峰叠波峰，亮；差半个波长的地方，波峰对波谷，暗。于是出现明暗相间的条纹。把光标放到底片附近验证一下——亮纹处的 Δr/λ 总是接近整数。

Δr = r₂ − r₁ = mλ  →  亮纹     Δr = (m+½)λ  →  暗纹

在小角度下这给出条纹间距的常用公式：

Δy = λL / d

把 λ 拉大或把 d 拉小，条纹立刻变宽。注意画面上的条纹在边缘会略微变疏——因为程序算的是严格的 r₂ − r₁，而 λL/d 只是小角近似。

还有第二个尺度：缝宽

条纹为什么中间亮、越往边上越暗？因为每条缝本身有宽度 a，单条缝的衍射已经把光限制在一个角宽约 λ/a 的包络里。于是图样有两个尺度嵌在一起：

细结构（双缝干涉）Δy = λL/d   ≪   粗结构（单缝包络）半宽 = λL/a

把缝宽 a 拉到最大，包络收窄，边缘条纹几乎全灭；把 a 拉小，包络铺平，整屏都是等强度的条纹。这也解释了 d 和 a 必须都很小才做得成实验：d 决定条纹够不够宽，a 决定光铺得够不够远。

试试 勾上「单缝包络」，然后单独拉缝宽 a。青线（有干涉）永远贴着紫虚线（无干涉）起伏，紫虚线就是它的上限包络。

经典的小球图像无论如何也给不出条纹：两个洞各射出一堆小球，屏上只该有两堆。

二

把光调到极弱：一个一个地到

现在把发射率降到最低，让装置里同一时刻只有一个粒子。底片上每次只闪出一个孤立的点，位置随机——这是彻头彻尾的粒子行为：能量一份一份地到达，从不出现"半个亮点"。

但让点累积上万次，条纹又长了出来。所以条纹并不是"许多粒子彼此干涉"的结果：单个粒子的落点概率分布本身就带着干涉结构。玻恩规则说概率密度是 |ψ|²，而两条缝的贡献要先把复振幅相加、再取模平方：

P = |ψ₁ + ψ₂|² = |ψ₁|² + |ψ₂|² + 2 Re(ψ₁*ψ₂)  ≠  |ψ₁|² + |ψ₂|²

多出来的那一项就是干涉项，它带着相位差。这也是为什么切到「强度」视图时画面是静止的：概率密度不含时间，只有振幅本身在振荡。

粒子在飞行途中被画成横跨两缝的一片亮雾，是有意为之：量子力学不给"它从哪条缝过去"这个问题准备答案。这不是"我们不知道"，而是——只要不去测，这个问题在理论里没有对应的物理量。

试试 把发射率拉到 1/s，盯着底片看半分钟：你看不出任何规律。这就是单次实验能给你的全部信息。规律只存在于统计里。
三

路径信息与可见度：一场连续的交易

在两条缝上各放一个探测器记录粒子走了哪条，条纹就消失。常见的解释是"测量太粗暴，把粒子撞歪了"。这个说法不准确：即使用极其温和、几乎不传递动量的方式取得路径信息，干涉照样消失。关键在于"哪条缝"的信息是否原则上可以被读出，哪怕没有任何人真的去读。信息一旦与环境纠缠（退相干），两条路径的相位关系就不再确定，干涉项被平均掉。

而且这不是非黑即白的开关。条纹可见度 V 与路径可辨识度 D 之间有一条严格的取舍关系（Greenberger–Yasin，1988）：

V² + D² ≤ 1

这就是实验台上那个「路径可辨识度 D」滑块的含义。它不是美术效果：程序按 V = √(1 − D²) 采样落点，读数条里的「V 实测」是从实际累积的直方图里锁相提取出来的，你可以自己核对它有没有落在理论值上。

V² + D² = 1 · 当前工作点

右图这条四分之一圆弧是理论上限。青点是当前设置对应的理论工作点，橙圈是从直方图里真实测出来的可见度（累积到几千次以后才稳）。

两个端点是熟悉的极端：D = 0、V = 1 是完美条纹，"哪条缝"完全无从谈起；D = 1、V = 0 是完全确定的路径，图样退化成两条缝各自衍射斑的简单叠加。中间的每一点都是真实可实现的状态——比如 D = 0.6 时 V 还有 0.8，条纹依旧清楚可辨，只是浅了一点。

试试 把 D 定在 0.71 附近（V 也约 0.71），点「累积 20 000」。条纹还在，但明暗对比明显减半——一半的路径信息，换掉一半的条纹。

D = 1 时的图样值得多看两眼。它不是教科书插图上常画的"两条细亮带"——那是几何投影（近场）才有的样子。在这台装置的距离上，每条缝的衍射斑已经铺得很开、几乎完全重叠，所以关掉相干性后剩下的是一个宽阔的单峰包络。要看到分开的两条带，得把缝宽 a 拉大（衍射变弱、光走直线）同时把 d 拉大：这时候即使 D = 0，两个斑也只在中间那一小块重叠区里才有条纹。

四

延迟选择：粒子过缝之后再决定要不要测

一个自然的反问：粒子会不会在到达双缝之前就"打探"好了装置的设置——看到探测器开着就走一条缝，看到关着就走两条缝？惠勒 1978 年提出的延迟选择实验就是为了堵死这条退路：等粒子已经通过双缝、正在飞向底片的途中，再决定打开或关闭路径探测。

结果是：图样只取决于最终实际做了哪种测量，与决定的时刻无关。这台实验台上的「演示延迟选择」按钮就是这个流程——先放出一批不受观测的粒子，等它们飞到半路再把探测器打开，落点分布立刻按"有路径信息"的分布重新给出。

试试 把时间流速降到 0.3×，然后点「演示延迟选择」。你会看到一片弥散的亮雾在半途突然坍缩成几条确定的轨迹。

反过来也成立，而且更有意思：如果路径信息被记录在某个辅助系统里，而你事后把这份记录擦掉（用一种原则上无法再区分路径的方式测量它），干涉条纹会重新出现。这叫量子擦除（Scully–Drühl，1982）。它常被说成"未来影响了过去"，但更清醒的读法是：条纹从来只出现在你对联合数据做了特定分选之后的子集统计里。你手上那份不分选的总数据，永远没有条纹，无论你事后擦不擦。

所有这些实验都不曾违反因果：谁也不能靠开关探测器向对面发一个比特。能改变的只有相关性的形态，不是任何一端单独看到的边缘分布。

五

不只光有：从电子到大分子

德布罗意（1924）把关系倒过来用：任何有动量的东西都有波长。

λ = h / p = h / mv   h = 6.626 × 10⁻³⁴ J·s

越重、越快的东西波长越短，条纹间距 λL/d 也就越小。这就是宏观世界看不见波动性的全部原因——不是没有，是太细了，细到远远小于任何可测的尺度。下面的计算器可以自己代数字试：

做成过的实验

  • 1801托马斯·杨用一束阳光和一张开缝的卡片看到条纹，把光的波动说重新推上台面。
  • 1909G. I. 泰勒把光弱到平均"三个月才积累够一张底片"，条纹依旧出现——弱光不破坏干涉。
  • 1927戴维森与革末用镍晶体衍射电子，德布罗意假设第一次被直接验证。
  • 1961约恩松做出真正的电子双缝（乃至三缝、五缝）干涉，不再借助晶体。
  • 1974–1989梅利与外方合作组、以及外村彰的团队完成单电子逐个累积的实验：底片上先是零散亮点，最后浮出条纹。
  • 1991卡纳尔与米隆尼用氦原子做出双缝干涉——干涉的对象已经是完整的原子。
  • 1999蔡林格小组让 C₆₀ 富勒烯（720 u，含 60 个碳核和 360 个电子）通过光栅并给出条纹。
  • 2013–2019阿恩特小组把纪录推到 10⁴ u 量级的有机大分子，λ 只有皮米的千分之几。

常见误解

  • "测量之所以毁掉条纹，是因为探测器撞歪了粒子。"动量扰动确实能毁掉条纹，但它不是根本原因。存在几乎不传递动量却能获取路径信息的方案（如用原子内部能级做标记），条纹一样消失；反过来，把标记擦除后条纹又能回来，而动量若真被随机撞乱是不可能复原的。根本的量是信息与纠缠，不是踢一脚的力度。
  • "需要有意识的观察者。"不需要。与环境发生足以区分路径的纠缠就够了，一个未被读取的探测器、一颗散射出去的光子、乃至分子自身的热辐射都能做到。这也是为什么大分子干涉实验必须做到极高真空、极低温：要防的是环境自己"读"了路径。
  • "粒子同时穿过两条缝。"这是个方便但会误导的说法。规范的说法是：不存在"它走了哪条"这个物理量的取值；参与干涉的是两条路径的概率幅。它也不是分成两半各走一半——探测永远抓到一整个。
  • "是许多粒子互相干涉。"不是。逐个发射、装置里同时只有一个粒子，条纹照样出现。干涉发生在单个粒子的概率幅之间。
  • "宏观物体不遵守量子力学。"遵守，只是波长太短、退相干太快。干涉条纹间距正比于 λ，而 λ = h/mv：桌球的条纹间距远小于原子核，没有任何装置能分辨。
  • "这说明现实由观察创造。"实验给出的是：某些经典问题（走哪条缝）在特定装置下没有答案，以及不同装置的结果互相约束。哪种本体论解释成立（哥本哈根、多世界、导波、退相干历史…）在实验上尚未分出胜负，双缝本身并不裁决。
结

那它到底是什么

  • 不是"有时是波、有时是粒子"，也不是"同时又是波又是粒子"。玻尔的互补原理：波动描述与轨迹描述是两套互相排斥、又缺一不可的语言，用哪一套取决于你搭了什么装置、问了什么问题。而 V² + D² ≤ 1 把这句哲学话变成了一条可以测量的定量关系。
  • 更现代的说法：它自始至终由一个量子态描述，既不是小钢珠也不是水面涟漪。"波"体现在概率幅的叠加与相位，"粒子"体现在探测永远是一次一整份。日常语言里没有对应的东西，所以只能借两个旧词轮流用。
  • 它是可计算的。上面这台装置里没有任何含糊之处：给定 λ、d、a 和 D，落点分布是唯一确定的，误差可以压到千分之几。"说不清"的只有我们想套上去的那套图像。

这台实验台做了哪些简化

  • 波长、缝距、缝宽都以屏幕像素为单位，比真实光学实验夸张了约 10⁹ 倍，否则条纹肉眼不可见。所有公式关系（Δy ∝ λL/d、包络 ∝ λL/a）都是严格成立的，只有绝对尺度是假的。
  • 波场用惠更斯次级源的相干叠加算出：每条缝按缝宽 a 铺开 2–9 个子波源，各源的振幅按 1/√r 衰减（二维柱面波）。这是标准的标量衍射近似，忽略了偏振与矢量效应。
  • 落点分布用 I(y) = A₁² + A₂² + 2V·A₁A₂·cos(kΔr) 采样，其中 Aᵢ 是各缝的单缝衍射振幅 sinc(πa(y−yᵢ)/λL)，Δr 用严格的距离差而非小角近似，V = √(1 − D²)。这是"每条缝各自向前投出一个衍射变宽的光束"的中场图像，介于严格远场与几何投影之间。
  • 动画里"某个粒子有明确路径 / 是一片亮雾"的二分只是示意画法：真实的部分测量让每一个粒子都处在部分相干的状态，而不是让一部分粒子被完全测量。整体统计遵循 V = √(1 − D²)，这一点是准确的。
  • 相位视图显示的是 arg ψ 相对当前时刻的值，色环无物理单位；强度视图不随时间变化，这不是程序卡住了。
  • 「V 实测」用直方图对严格路径差做锁相提取，在包络明显倾斜（缝宽 a 很大）时会略低于理论值，累积不足几千次时噪声也很大。
  • 延迟选择演示中，切换探测器时会对仍在飞行的粒子重新抽样落点。这正确地再现了"图样只取决于最终测量"，但不应被读成"粒子被追溯地改写了轨迹"。
