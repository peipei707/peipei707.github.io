# 颜文字图鉴（新版，试做中）

2,092 张颜文字，8 组 70 类，点一下就复制。合并到 `main` 之后的地址：<https://peipei707.github.io/kaomoji2/>

旧版「颜文字小铺」原样留在 [`../kaomoji/`](../kaomoji/)，这一版是另起炉灶重做的，两边互不影响。

## 能做什么

- **图鉴**：点一下复制，双击收藏，长按（电脑上右键）看详情。详情里会把一张脸拆开，告诉你每个符号是从哪种文字借来的，比如 ω 是希腊字母、๑ 是泰文数字。
- **搜索**：认识网络用语（笑死、emo、栓Q、awsl）和整句话（「今天好累想睡觉」），也能直接搜符号（ω、ᴥ）。
- **目录**：手机上点「目录」，电脑上在左边栏；分类条会跟着滚动走。
- **我的**：收藏、最近用过、自己捏的脸，还有一个收集进度（复制过的脸会留个小圆点）。设置里有深浅色、格子大小和稳妥模式（藏起可能显示成 □ 的脸）。
- **实验室**：九个小工具，分三组。
  - 换个说法：**花式文字**（删除线、圈起来、框起来、打码、鬼畜、蒸汽波宽字、英文花体和上标小字，四十来种）、**换个语气**（夹子音、猫猫语、发疯文学、火星文，或者按意思自动配颜文字）、**暗号机**（摩斯电码、盲文、隐形墨水；把收到的暗号粘贴进去会自动解开）。
  - 搞点动静：**举牌喊话**、**像素大字**（把一两个字放大成一整屏，用字本身、方块、爱心或盲文点阵拼）、**连发剧本**。
  - 捏一张，抽一张：**捏脸机**、**扭蛋机**、**颜文字签**。

  实验室里做出来的句子和暗号复制后不会记进「最近用过」。

收藏和记录只存在当前设备的浏览器里。

## 改内容

`index.html` 是生成出来的，不要直接改。改完下面这些文件后运行：

```sh
node build.js      # Node 18 以上，没有依赖
```

| 文件 | 放什么 |
| --- | --- |
| `data/*.txt` | 颜文字本体，按文件名顺序排 |
| `words.txt` | 搜索词典：网络用语、同义词对应到哪些标签 |
| `src/page.html` | 页面骨架 |
| `src/style.css` | 样式 |
| `src/app.js` | 图鉴、搜索、详情、我的 |
| `src/lab.js` | 实验室的九个小工具 |
| `src/unicode.js` | 字符知识：属于哪种文字、叫什么、少不少见、照镜子；构建和页面共用 |
| `src/fonts/` | 标题字体（站酷快乐体的子集），见里面的 README |

`data/*.txt` 的格式：

```
# mood | 心情 | 组的一句话介绍
## happy | 开心 | (◕‿◕) | 分类的一句话介绍 | 这一类共用的搜索词
(◕‿◕)	微笑
```

- `#` 开头是组，`##` 开头是分类：`id | 名字 | 代表脸 | 一句话 | 搜索词`。id 只用小写字母，会出现在网址里（`#c-happy`）。
- 颜文字一行一张，后面跟一个 **Tab**，再写这张脸自己的标签（空格隔开）。没有标签可以不写 Tab。
- 同一张脸可以放进好几个分类，搜索时只算一张。
- 好几行拼成的大图：用 `\n` 表示换行，并在标签里写上「多行」。
- 「零件」那一组只在图鉴里出现，不会被随机抽到。

构建时会检查：分类 id 重复、同一分类里的重复、`words.txt` 指向了不存在的标签、标题字体缺字，都会在终端提示。

## 两个约定

- 单个 HTML 文件，样式、脚本、数据、字体都在里面，不依赖外部资源，离线也能用。
- 每张脸都直接写在 HTML 里：没有 JavaScript 的环境（比如手机的文件预览）也能看到全部内容、长按复制。

## 实验室里几个工具的原理

- 删除线、下划线、圈、框这类效果，是在每个字后面加一个 Unicode「组合符号」（比如 U+0336），它会叠在前一个字身上。有的浏览器画不出叠在汉字上的组合符号，页面会先量一下，画不出来就用 CSS 模拟预览，复制出去的仍是真正的字符。
- 摩斯电码：字母、数字、标点按国际电码；汉字没有通用电码，先写成 Unicode 编号（我 = U+6211）再敲。
- 盲文：英文字母、数字和常用标点用一级英文盲文；其他字拆成 UTF-8 字节，每个字节放进一个 8 点盲文格。多字节字符的字节都 ≥ 0x80，正好落在带第 8 点的格子里，不会和 6 点盲文混淆，所以能原样解回来。中文盲文要按拼音写，这里的点阵只是暗号。
- 隐形墨水：悄悄话的每一位写成零宽空格（0）或零宽不连字（1），前后用词连接符（U+2060）包住，藏在第一个字后面。有的 App 会删掉这些字符。
- 像素大字：用画布把字画大，再按格子取样，墨够多的格子算「亮」。
